# 💫 MAS Submod - Little Bit of Everything
A submod that adds new topics, spritepacks, interactions, and more! Just an expansion-type submod to add a little more to your [Monika After Story](https://github.com/monika-after-story/monikamoddev)!

## ✨ Features
- Many new Added topics!
- 2 Added goodbyes and 6 added brbs!
- More Added compliments!
- A high or low game, and a finish the lyric game!
- 12 Spritepacks!
- 4 backgrounds, and 4 pong reskins!

## 🌕 Installation
The zip comes with *four* folders. If you are just interested in the submod, your focus will be on the `LBE` folder. This version (v1.1) does *not* come with the touch feature or the custom music.

If you have version 1.0 of this mod, please delete it and reinstall this version! It fixes major bugs.

Download the [latest release](https://github.com/betapop/Beta-MAS-lbe/releases) and extract the zip.

### LBE Folder
Take the `game` folder and drag it into your DDLC folder. This folder could be named something like `DDLC-1.1.1-pc`! Place the `game` folder inside this folder and let it write into/override the content.

### Rooms Folder
This folder has the four custom backgrounds and requires the [Room Selector](https://github.com/tw4449-s-MAS-Submods/tw4449-Custom-Room-Selection-Pack-Main-Repository) and 400+ affection. It installs like normal, and you can drag the `game` folder inside your DDLC folder.

### Pong Reskins Folder
Self explanatory, these are pong reskins! These replace the `pong_field.png` file. You can select the reskin you're interested in and merge it with your `mod_assets` folder. I'm sure you could also use [Emerald Box](https://github.com/zer0fixer/MAS-EmeraldBox/releases/tag/1.0.3), if you want to switch between them! <sup><sub>Though no tutorial from me....</sub></sup>

### Spritepacks Folder
This is a collection of all of the spritepacks together, intended to be installed together. Once again, you simply drag both folders into your DDLC folder and merge! You will also need [Selector City](https://github.com/mayday-mayjay/MJ-MAS-selector-city) for many of the spritepacks.
